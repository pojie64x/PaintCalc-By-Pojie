# Paint & Surface Calculator by Pojie

A free, single-file web app for paint estimating and surface calculation.

## Features
- **Paint:** litres, cans and cost (RM) from area, DFT, volume solids, coats and loss factor
- **Area:** add/subtract surfaces, convert m², ft², yd², cm², in²
- **Shapes:** general shapes plus oil & gas (pipe, elbow, reducer, flange, valve, tanks, steel beam)
- **DFT / WFT / Spreading rate** calculators
- Metric and imperial (m / ft)

## Use
Open `index.html` in a browser, or host it with GitHub Pages.

## Formulas
- Spreading rate (m²/L) = volume solids × 10 ÷ DFT
- DFT = WFT × VS ÷ 100
- WFT = DFT × (1 + thinner ÷ 100) ÷ (VS ÷ 100)

Values are estimates. Check your product data sheet.
